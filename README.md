# RAG-dengan-gemini-2.5-flash
chatbot dengan rag pdf gemini flash 2.5

jalankan perintah ini untuk membuat virtual environment
python3 -m venv venv

Selanjutnya jalankan di Linux / Codespaces:
source venv/bin/activate

Selanjutnya jalankan:
Upgrade pip
pip install --upgrade pip

selanjutnya Install semua library
pip install -r requirements.txt

Set API Key Gemini

Di terminal:

export GOOGLE_API_KEY="API_KEY_KAMU" ada di kode ya

selanjutnya Jalankan Streamlit
streamlit run app.py
